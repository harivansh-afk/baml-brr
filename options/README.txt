The first implementation is rust/mir-to-rust.

Each README records the approach, confirmed evidence, current scope, and the
next unresolved question. A baml/ worktree appears when that option starts.
The code branch is recorded beside it. Build outputs stay untracked.

We will explore one route at a time. The next route starts from the recorded
baseline, rather than inheriting experimental changes accidentally. Shared
fixes can be moved between branches deliberately once they are understood.
